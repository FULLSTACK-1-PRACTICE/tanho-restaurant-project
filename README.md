# Tanho Restaurant

Tanho Restaurant — restoran uchun ishlab chiqilayotgan web application.

Ushbu loyiha SFERA IT Academy'dagi fullstack 1 jamoasining frontend yonalishi tugallanganligi munosabati bilan ularning Amaliyot sifatidagi real loyihasi. Loyiha orqali real loyiha ustida ishlash, Git va GitHub bilan jamoaviy ishlash hamda frontend development jarayonlarini amalda qo‘llash maqsad qilingan.

## About the Project

Loyihada restoran faoliyati uchun bir nechta foydalanuvchi rollari mavjud:

* User
* Admin
* Cashier
* Manager

Har bir rol uchun alohida dashboard ishlab chiqilmoqda.

### User

User restoran saytidan foydalanib, menyuni ko‘rishi, buyurtma berishi va stol band qilishi mumkin.

### Admin

Admin panel orqali bugungi daromad, buyurtmalar va stol band qilishlar haqidagi ma'lumotlarni ko‘rish va boshqarish imkoniyati mavjud.

### Cashier

Cashier panelida to‘lovlarni qabul qilish va bugungi buyurtmalarni ko‘rish hamda boshqarish imkoniyatlari mavjud.

### Boss

Boss dashboard orqali restoran faoliyatiga oid asosiy ma'lumotlarni ko‘rish imkoniyati mavjud.

## Practice

Ushbu loyiha SFERA IT Academy FULLSTACK 1 GURUHI TOMONIDAN  Amaliyot doirasida ishlab chiqilmoqda.

Loyiha ustida jamoa bo‘lib ishlanadi. Vazifalar GitHub orqali taqsimlanadi. Har bir developer o‘z vazifasi uchun alohida branch yaratib ishlaydi va tayyor bo‘lgan o‘zgarishlarini Pull Request orqali yuboradi.

Asosiy ish jarayoni:

```text
Issue → Branch → Development → Commit → Push → Pull Request → Review → Merge
```
